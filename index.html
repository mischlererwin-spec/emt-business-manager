Wichtiger Hinweis zur Installation unter Windows (SmartScreen)

EMT Business Manager ist eine unabhängig in der Schweiz entwickelte Software. Da neue Programme ohne teures Grosskonzern-Zertifikat von Windows beim ersten Start standardmässig mit einem blauen Hinweisfenster („Der Computer wurde durch Windows geschützt“) gemeldet werden, gehen Sie bei der Installation bitte wie folgt vor:

  1. Laden Sie die ZIP-Datei herunter und entpacken Sie sie in einen Ordner.
  2. Starten Sie setup.exe und klicken Sie im blauen Windows-Fenster auf Weitere Informationen.
  3. Klicken Sie anschliessend unten auf Trotzdem ausführen.
  4. Das Programm installiert sich sofort und startet automatisch in Ihre kostenlose 14-Tage-Testversion.
